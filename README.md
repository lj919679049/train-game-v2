# 快乐号小火车 3D（V2）

**在线玩：<https://lj919679049.github.io/train-game-v2/>**

《快乐号小火车》的 3D 重制版（V2）。V1 是手绘绘本风的 2D 小火车；V2 把游戏搬进三个等距
微缩 3D 世界——**雪夜电车、穿越大海、黄昏穿越城市**——玩法、路线、语音、音效、数学题与
V1 完全一致，美术整体换成可旋转、可跟车运镜的 Three.js 3D 场景。

![黄昏穿越城市](https://lj919679049.github.io/train-game-v2/preview-3d-city.png)

## 三个 3D 世界 × 10 个车站

| 车站 | 3D 世界 |
| --- | --- |
| 上海 / 南京 / 天津 | 黄昏穿越城市（河畔高楼、古城墙、摩天轮之夜） |
| 苏州 / 无锡 / 盐城 / 连云港 / 青岛 | 穿越大海（水乡白昼、湿地晨光、灯塔海湾） |
| 济南 / 北京 | 雪夜电车（雪夜小村、雪夜城镇） |

## 玩法

1. 在「列车设计站」选火车头 / 车厢 / 汽笛 / 乘客样式（3D 转台实时预览）
2. 到站：**打开车门** → 看 3D 乘客上下车 → **关闭车门**
3. **烧锅炉 × 3**（压力到 100%）→ **释放蒸汽**（拉响汽笛）
4. 跟着列车穿过三个世界，答对车站数学题拿分

支持鼠标拖动旋转、滚轮缩放，右下角可重置视角；手机竖屏和桌面横屏都可玩。
